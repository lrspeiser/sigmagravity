# P0689 source-routing audit snapshot

Frozen before metrics: 2026-08-02

## Bottom line

After retiring the scalar local-path exponent family, the first genuinely
different source-placement operator passes its mathematical and numerical
audit. It has not yet been scored on a galaxy or lens.

The operator preserves fixed-RAR QUMOND, measures the positive strength of the
old local-path generator, routes that strength onto the observed baryonic
morphology, and places an equal negative polarization source on the existing
potential-transition shell. The added source integrates to zero, so the
far-field monopole is conserved.

On the spent registered RX J2129 map:

- routed Poisson residual: `2.47e-14`;
- positive/negative strength mismatch: `1.57e-16`;
- net added source / positive strength: `9.29e-17`;
- transition-shell interior weight: `78.1%`;
- fitted gravity/photon amplitudes: `0/0`; and
- photon, radial, raw-image, or sealed score computed: none.

This earns permission to freeze the spherical galaxy/cluster transfer and raw
3D topology tests. It is not evidence that either will pass.

gateway backed by isolated asynchronous workers. Its API will support named
real systems, seeded synthetic systems, safe unit-aware formula submissions,
batch comparator scoring, solver diagnostics, and immutable data/formula/result
hashes. Heavy 3D fields and lens-root searches belong on Cloud Run Jobs or
Modal rather than Vercel request functions.
