# P0585 local-attractor results

## Result in plain language

Replacing one global return destination with multiple baryon-derived local
destinations does not materially improve the RX J2129 result. The best local
map reduces held-out RMS from 1.24301 arcsec for the smooth global no-cross map
to 1.24235 arcsec, only 0.053% better. All neighborhood-coordinate effects are
below 0.001 arcsec.

This closes an important ambiguity from P0583-P0584. The global centroid was
not uniquely responsible for the failure. RX J2129 only tolerates an endpoint
amplitude near 0.005; at that scale, changing destinations barely matters. At
larger amplitudes the exact lens roots become unstable. Continuing to tune
endpoint geometry would therefore optimize a negligible channel rather than
build a useful universal field.

## Local-attractor formula

For source `i`, a destination was derived only from the other cataloged
baryonic sources:

\[
\mathbf c_i=
{\sum_{j\ne i}w_jK_{ij}\mathbf x_j
 \over
 \sum_{j\ne i}w_jK_{ij}},
\qquad
K_{ij}=\left(|\mathbf x_i-\mathbf x_j|^2+h^2\right)^{-p/2}.
\]

The destination was mixed with the global baryonic centroid,

\[
\mathbf d_i=(1-\mu)\mathbf c_{\rm global}+\mu\mathbf c_i,
\]

and the source approached it without crossing:

\[
\ell_i=L\tanh\left({|\mathbf d_i-\mathbf x_i|\over L}\right),
\qquad L=0.36R_{80}.
\]

The K0338 concentration gate, `0.23 R80` endpoint width, tanh-20 contrast
transform, P0554 carrier, and exact annular monopole removal were unchanged.
The Solar single-source route collapses exactly because it has no separate
local attractor.

## Screen

The structural grid crossed:

- local mix `mu = 0.25, 0.5, 0.75, 1`;
- softening `h/R80 = 0.1, 0.25, 0.5, 1`;
- distance power `p = 1, 2`;
- seven positive amplitudes from 0 to 0.025.

Together with the global no-cross control, this produced 33 destination maps
and 231 exact-root scores at the frozen scalar geometry and source positions.

| Formula | `epsilon` | Held-out roots | Held-out RMS |
|---|---:|---:|---:|
| Scalar / zero endpoint | 0 | 7/7 | 1.25617 arcsec |
| Global tanh no-cross | 0.005 | 7/7 | 1.24301 arcsec |
| Best local attractor | 0.005 | 7/7 | **1.24235 arcsec** |

The best local structure used `mu=0.25`, `h=0.1 R80`, and `p=1`. It improved
the scalar baseline by about 1.10%, but only 0.053% of that comparison separates
it from the already selected global no-cross map. This is opened-data
description, not validation.

The median coordinate spans were:

| Coordinate | Median complete-root RMS span |
|---|---:|
| Local/global mix | 0.000665 arcsec |
| Neighborhood softening | 0.000484 arcsec |
| Distance power | 0.000124 arcsec |

All fields conserved their route-map normalization to `2.22e-16`, annular
monopole to `2.78e-16`, and normalized curl to `3.34e-17`. No smooth route
crossed its derived destination.

## Decision

The zero-monopole endpoint channel should not be developed further as the main
cluster-lensing mechanism:

1. unit strength failed RX J2129 by more than a factor of ten in residual;
2. root-safe strength is about 0.005 in that system;
3. sign reversal does not help;
4. no-cross travel is cleaner but adds only about one percent; and
5. multiple local attractors add only another 0.053%.

The inverse origin-to-halo transport remains useful as a descriptive diagnostic
of where an apparent response would have to travel. It has not yielded a
baryon-only forward endpoint law that predicts raw lens images. The next field
branch should alter the continuous metric/tidal response generated by baryons,
or add measured gas and diffuse light, instead of depositing a separate
endpoint map.
