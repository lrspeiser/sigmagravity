# P0617: self-coupled support and phase atlas

P0617 keeps the P0615 strength law fixed:

\[
f_{\rm self}={\Delta_{80}\over1+\Delta_{80}},\qquad
\epsilon={Q^2\over1+\Delta_{80}}.
\]

It changes only where the routed baryonic field is deposited. Nineteen
dimensionless laws make small changes to the base width (0.23R_{80}), return
length (0.36R_{80}), or center-crossing rule. Width and length factors are
built only from the observed member-light quadrupole (Q), including
(1/(1+Q)), \(\sqrt{1-Q^2}\), and their widening counterparts. No route
coefficient is fitted to any cluster.

The raw exact-root response is measured at the same frozen geometries used in
P0615 for MACS0329, MACS0429, MACS1115, MACS1931, and RXJ2129. Galaxy rotation
and Solar constraints remain inherited exact nulls of the angular layer. This
is explicitly an opened-data sensitivity atlas; a selected law requires a new
full-refit transfer before it can be treated as a candidate.

## Result

The safety-first diagnostic is

\[
w=0.23R_{80}\sqrt{1+Q^2},\qquad \ell=0.36R_{80},
\]

with the original constant-travel rule. It retained 18/18 roots, improved the
mean of the five per-system responses by 0.227%, improved the four-cluster RMS
by 0.132%, and improved RXJ2129 by 0.892%. It nevertheless improved only 2/5
systems; the worst response was a 0.514% deterioration. It therefore fails the
cross-system consistency gate.

The response spans show that coupled width/length changes were most influential
(0.289 percentage points in mean response), followed by width (0.256), return
length (0.228), and the center-crossing rule (0.095). These are local
sensitivities, not evidence for the physical correctness of any law.

The sign split is the strongest result. At the fixed P0615 support, the route
shift pointed against the existing residual for MACS1115 and RXJ2129 and both
improved. It pointed with the residual for MACS0329, MACS0429, and MACS1931 and
all three worsened. This 5/5 sign correspondence is a first-order geometric
identity, not an independently predicted success. It says that scalar shape
measures such as \(Q\) and \(\Delta_{80}\) can control amplitude and width but
cannot choose the needed angular phase. A defensible next law must predict that
phase from baryonic observables fixed before inspecting the lens residual—for
example stellar/gas centroid offsets, external tidal direction, or member-light
multipole orientation. Using the residual itself would merely fit the answer.
