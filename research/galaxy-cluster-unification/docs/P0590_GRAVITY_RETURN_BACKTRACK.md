# P0590: gravity leaves and returns to the observed slice

P0590 translates the proposed picture into a conservative test. In a field with one extra route coordinate, only baryons source the full flux. An observer who calculates divergence in the visible two-dimensional slice misses flux that leaves or re-enters through the hidden direction. A return location can therefore look like an additional projected mass concentration even though the full equation contains no non-baryonic source.

The first testable approximation is deliberately simple: each element of the frozen baryon map sends a universal fraction of its field into a ring-shaped return distribution. The return distance is a dimensionless multiple of the baryonic acceleration-transition scale, `sqrt(G M_b/a0)`. The kernel integrates to one, so it redistributes field weight instead of creating it.

For any apparent-dark residual peak, Bayes' rule can run this law backward. A baryonic source is probable when it is massive and its distance from the peak lies near the locked return radius. The output table reports the most probable source or component and the size of the simplest illustrative hidden semicircle.

The parameter choice uses two parametric public MACS J0416 maps. It then transfers unchanged to one non-parametric strong-plus-weak map and one free-form strong-lensing map. These are method holdouts, not independent observations: all reuse much of the same lensing sky data and all assume conventional lensing when reconstructing convergence.
