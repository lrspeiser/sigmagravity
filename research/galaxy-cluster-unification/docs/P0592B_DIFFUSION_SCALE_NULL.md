# P0592B: does the adaptive scale matter?

P0592 greatly improved over a minimally smoothed member-light map, but earlier work showed that a fixed 100 kpc blur was already a strong description. P0592B selects a fixed physical width on the same seven development clusters and transfers it beside the already locked `ell=0.5 R80` propagator.

The adaptive rule is informative only if it beats the selected fixed blur materially on development, Lenstool holdouts, and GLAFIC holdouts, with at least two of three holdout clusters improving individually.
