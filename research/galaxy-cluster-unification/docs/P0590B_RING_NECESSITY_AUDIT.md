# P0590B: is it really an arc, or just smoothing?

P0590 selected the shortest, broadest, fully routed ring. That result can fit well while still failing to identify the proposed mechanism, because a broad ring with substantial density at its center resembles ordinary Gaussian smoothing.

This audit explicitly includes zero-radius kernels. It locks the best unrestricted return model, the best Gaussian-smoothing null, and the best strict annulus on the same development maps, then transfers each to the same two method holdouts. The arc interpretation requires a nonzero return radius to beat the Gaussian by a material margin and requires the narrower annulus to beat it on both holdout reconstructions.
