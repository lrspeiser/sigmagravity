# P0589: a target-blind MACS J0416 baryon field

This stage builds the source side needed for a curved-gravity-route experiment. It registers spectroscopic member light, two independently catalogued BCGs, four published Chandra-derived gas dPIE components, and an explicit bounded ICL nuisance on one coordinate system.

Nothing in the construction reads a convergence map, a fitted dark-halo center, or an image residual. The ICL is not presented as measured: BUFFALO subtracted it before catalog production, so P0589 varies a transparent elongated component from zero to 30% of the discrete stellar mass.

The same frozen P0586D metric formula is evaluated under 13 one-at-a-time baryonic changes. This tells the next inverse-route stage which apparent features are robust to membership, aperture, stellar mass-to-light behavior, gas normalization, ICL, and the southern-BCG mass. It does not test whether the field explains lensing.

The next stage must freeze a conservative route law before opening public MACS J0416 convergence maps. A valid backtracking result will require agreement across independently produced maps and a target-free control—not just drawing an arc from a lensing peak to the nearest bright galaxy.
