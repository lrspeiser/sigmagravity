# P0591: a baryon-directed return annulus

The isotropic P0590 ring did not separate itself from Gaussian smoothing. P0591 asks whether the missing information is direction rather than radius. It modulates a genuinely displaced annulus by the major axis of the frozen baryonic second-moment tensor. No lensing map chooses that axis.

The directional kernel remains positive and unit normalized. A 45-degree rotated-axis control asks whether any gain is specifically associated with the baryonic geometry. The model advances only if it beats Gaussian smoothing materially on development and both method holdouts, and if the true baryon axis beats the rotated control.
