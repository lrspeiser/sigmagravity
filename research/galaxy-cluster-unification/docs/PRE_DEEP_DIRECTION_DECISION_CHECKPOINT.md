# Pre-deep direction decision checkpoint

Date: 2026-08-05

## Purpose

This checkpoint prevents the project from spending months refining infrastructure or empirical interpolations before one physical mechanism has earned deeper development. It does not weaken the final Sigma Gravity success criteria and does not authorize an action, gravity parameter, lensing fit, galaxy refit, Solar-System optimization, or holdout access.

## What the existing evidence already decides

| Mechanism family | Evidence already obtained | Pre-deep disposition |
|---|---|---|
| Scalar low-acceleration or density-amplitude interpolation | Competitive galaxy amplitudes and strong agreement with NFW-derived radial cluster fields, but raw multi-cluster lensing generally lacks the required image multiplicity and topology | Retain as a comparator; do not deepen as the primary theory |
| Component-wise nonlinear baryonic response | Applying the nonlinear response before summing separated baryonic components increased raw image-root completeness to 85.1% in one cluster and 55.6% in another | Continue only through the frozen source-invariant gate; this is the leading physical clue, not a passing theory |
| Constrained composite response (P1) | Can represent component overlap and directional response without an independently fitted halo state if its constraints close | Conditionally eligible only after V19BQ/V19BS authorization |
| Degenerate pure-metric nonlinear vertex (P3) | Offers the lowest extra field content but has unproven conservation, degeneracy and ghost freedom | Conditionally eligible only after V19BQ/V19BS authorization |
| Causal dynamic or memory response (P2) | Static merger snapshots contain no time-odd current or independently clocked lag | Not authorized without direct velocity or time-lag evidence |
| QED/observation-only deflection, variable-G, void-pressure, variable-exponent and wave-length sketches | None has passed one frozen universal raw multi-cluster lensing test while retaining the galaxy result | Archive as explored hypotheses; do not select for deep work now |

The present problem is spatial structure, not average force amplitude. A viable mechanism must generate the Hessian of the lensing potential in the correct locations and orientations from baryons, rather than multiplying a broad radial field.

## Remaining gates before selecting a deep direction

### Gate 1: terminal source reconstruction

Complete the frozen source-only chain:

1. V19X2 integrated and selected-region spectral commissioning for Abell 2146 and the Bullet Cluster.
2. V19X3B all-494-region combination and temperature fitting with the identical rules.
3. V19X4B gas-posterior construction.
4. V19BMB stellar-control construction.

A valid frozen scientific failure stops this source route. It is not repaired by changing grouping, energy range, cell membership, fit bounds, cluster membership or gravity physics.

### Gate 2: V19BQ source invariance

The observed baryonic source candidate must satisfy all of the following without lensing or halo information:

- I4 directional agreement passes both clusters;
- all three registered dependence branches pass;
- all six registered spatial variants pass;
- and either I4 amplitude or the I5 scalar condition passes everywhere.

This is 72 preregistered candidate evaluations. Passing means the projected baryonic geometry is robust enough to motivate a field equation. It does not mean the gravity theory works.

### Gate 3: V19BS disposition

- If V19BQ fails, action derivation is not authorized. The registered I4/I5 source mechanism is falsified on the two development mergers. The next admissible evidence is direct gas velocity, an independently clocked merger lag, or an independent merger sample evaluated with unchanged source definitions.
- If V19BQ passes, P1 and P3 are eligible for a mathematical comparison. P2 remains excluded without time-odd evidence.

### Gate 4: minimum mathematical comparison

Derive no more than the minimum representatives required to compare P1 and P3. Select between them without galaxy or lensing scores, using only:

- a complete diffeomorphism-invariant action;
- closed constraints and an explicit degree-of-freedom count;
- Bianchi-compatible conservation;
- a bounded Hamiltonian and healthy kinetic/gradient terms;
- a causal or properly constrained initial-value problem;
- one physical metric for matter and light;
- no independent halo-shaped initial condition;
- no more than five universal physical constants;
- a GR/Newtonian high-field limit.

The mathematically healthy option with the least field content is the only one admitted to the observational kill test.

### Gate 5: inexpensive cross-scale kill test

Before a broad solver, holdout or Solar-System campaign, the selected action must demonstrate on development data that it can:

- reproduce the already-established galaxy low-acceleration behavior without a galaxy label or per-galaxy gravity parameter;
- create the observed strong-lensing image multiplicity and critical-curve topology in at least two morphologically different development clusters;
- materially improve image positions over baryons-only GR with one universal parameter set;
- use the same physical metric for stellar motion and photon propagation.

Failure here stops that action. It is not repaired with a lensing-only multiplier, cluster-specific shear, orientation, scale, amplitude or source definition.

## Decision outcomes

| Terminal result | Decision |
|---|---|
| Source reconstruction fails a frozen scientific gate | Do not derive an action from this source chain; document the source-method failure and reassess the observational source evidence |
| V19BQ fails | Falsify the registered I4/I5 route; collect time-resolved or independent-merger evidence before revisiting it |
| V19BQ passes and only P1 is mathematically healthy | Select P1 for the inexpensive cross-scale kill test |
| V19BQ passes and only P3 is mathematically healthy | Select P3 for the inexpensive cross-scale kill test |
| Both are healthy | Select the option with fewer healthy degrees of freedom and less independent field content, without consulting gravity targets |
| Neither is healthy | Stop this mechanism family; do not invent another interpolation |
| Selected action passes the cross-scale kill test | Begin the full action, solver, frozen-split, raw-lensing, weak-lensing and later Solar/PPN program |
| Selected action fails | Record one materially distinct action failure toward the three-closure falsification rule |

## Work explicitly deferred

Until one action passes the cross-scale kill test, do not spend substantial effort on:

- detailed Cassini, Mercury or gravitational-wave propagation calculations;
- large holdout samples;
- weak-lensing and magnification production runs;
- additional empirical bridge terms;
- per-object nuisance optimization beyond declared measurement uncertainties;
- public simulator feature refinement unrelated to the selected action.

Solar-System, propagation, stability and conservation constraints remain final hard vetoes. They are deferred, not waived.
