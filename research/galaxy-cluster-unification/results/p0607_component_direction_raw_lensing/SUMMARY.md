# P0607 component-direction raw-lensing test

Training selected the positive route **gas** at **s_theta=0.0025**. After an 8-start geometry refit its training/held-out RMS is **0.4952/1.8106 arcsec** versus the P0599 no-route reference **0.4952/1.8087 arcsec**.

The opposite-sign control selected **stars**, **s_theta=-0.005**, and refit to **0.4946/1.8259 arcsec**.

The component maps set direction only; no X-ray count rate is interpreted as gas mass. RX J2129 is spent, so this is a mechanism diagnostic rather than confirmation.
