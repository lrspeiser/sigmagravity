# P0721 formula-independent batch API

This directory records the strict real-HTTP acceptance result for the local
multi-system 3D batch path. `report.json` is the compact result and
`per_galaxy.csv` preserves the numerical diagnostics for all three generated
DDO101 variants.

This is an infrastructure and numerical-convergence milestone. It is not a
rotation-curve, lensing, or theory-validation result. See
`../../docs/ASYNC_MULTI_SYSTEM_BATCH_API_MILESTONE.md` for the procedure,
claim boundary, and remaining production requirements.
