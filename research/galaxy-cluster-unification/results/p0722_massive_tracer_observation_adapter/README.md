# P0722 massive-tracer observation adapter

This directory records the first formula-independent observation-space score
produced through the generic local API. `ddo101_curve.csv` and
`ddo101_curve.png` compare the solved Newtonian field with all ten published
DDO101 circular-speed points and with an earlier frozen Newtonian
implementation. `report.json` records the content-addressed batch identity and
deterministic metrics.

The result validates the adapter and exposes the expected Newtonian baryonic
shortfall. It does not test photon lensing or establish a new gravity theory.
See `../../docs/MASSIVE_TRACER_OBSERVATION_ADAPTER_MILESTONE.md` for the full
claim boundary.
