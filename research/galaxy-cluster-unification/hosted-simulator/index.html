Scientific boundary

A test bench, not a claim of discovery.

This hosted fast path evaluates published radial baryonic mass-model components. It does not pretend that algebraic circular-orbit tests are full AQUAL, QUMOND, or relativistic lensing solutions.

The local reference API now composes immutable 2D/3D field jobs with separately cached observation jobs across multi-system batches, including typed photon deflection, convergence, shear, rotation, and magnification maps. Public durable workers and raw multiple-image root fitting remain deployment milestones, so hosted heavy routes disclose that limitation.

For notebooks and pipelines

Use the API directly

OpenAPI JSON
GET/api/v1/systems?q=DDO

Search real galaxies and inspect supported tests.

POST/api/v1/formulas/validate

Check symbols, dimensions, parameter policy, complexity, and canonical hash.

POST/api/v1/models/validate

Validate scalar, vector, or tensor field equations in 2D or 3D without theory-specific code.

POST/api/v1/field-jobs/prepare

Bind a model to content-hashed arrays, grid, boundaries, observables, and a resource estimate before queueing.

POST/api/v1/data-uploads

Register immutable NPZ data; the development backend verifies byte hashes before a job can use it.

POST/api/v1/field-jobs

Queue a confirmed 2D/3D manifest locally, then poll state, events, and verified artifacts. Production workers are not connected yet.

POST/api/v1/observation-evaluation-jobs

Reuse one immutable solved field with new observation data, masks, beams, or uncertainties without rerunning gravity.

POST/api/v1/galaxy-jobs

Extract content-hashed baryonic parameters or generate verified 2D/3D density bundles without choosing a gravity formula.

POST/api/v1/batches

Compose reusable field solves with separately hashed observation data and targets across uploaded or generated systems, then download one deterministic report.

POST/api/v1/runs

Run a formula and receive scores, curves, comparators, and an immutable manifest hash.
