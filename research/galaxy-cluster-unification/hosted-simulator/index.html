Scientific boundary

A test bench, not a claim of discovery.

This hosted fast path evaluates published radial baryonic mass-model components. It does not pretend that algebraic circular-orbit tests are full AQUAL, QUMOND, or relativistic lensing solutions.

The local reference API now composes immutable 2D/3D field jobs with separately cached observation jobs across multi-system batches, including typed photon deflection maps and raw multiple-image source profiling, global root finding, assignment, and uncertainty-aware image-position scores. It also infers one shared stationary response kernel from explicitly labeled baryonic maps and model-derived targets, with uncertainty, null controls, and non-identifiability diagnostics. That inverse is a hypothesis generator, not a forward theory test. Public durable workers remain a deployment milestone, so hosted heavy routes disclose that limitation.

Use the API directly

OpenAPI JSON
GET/api/v1/systems?q=DDO

Search real galaxies and inspect supported tests.

POST/api/v1/formulas/validate

Check symbols, dimensions, parameter policy, complexity, and canonical hash.

POST/api/v1/models/validate

Validate scalar, vector, or tensor field equations in 2D or 3D without theory-specific code.

POST/api/v1/models/confirm

Bind a researcher acknowledgement to the exact validated equation hash before execution.

POST/api/v1/field-jobs/prepare

Bind a model to content-hashed arrays, grid, boundaries, observables, and a resource estimate before queueing.

POST/api/v1/data-uploads

Register immutable NPZ data; the development backend verifies byte hashes before a job can use it.

POST/api/v1/field-jobs

Queue a confirmed 2D/3D manifest locally, then poll state, events, and verified artifacts. Production workers are not connected yet.

POST/api/v1/observation-evaluation-jobs

Reuse one immutable solved field with new observation data, masks, beams, or uncertainties without rerunning gravity.

POST/api/v1/galaxy-jobs

Locally extract content-hashed baryonic parameters, generate seeded 2D/3D ensembles, or weight surface draws with declared gas/stellar uncertainty maps without choosing a gravity formula.

POST/api/v1/inverse-response-jobs

Infer a shared candidate baryon-to-response kernel locally from model-derived discovery targets, with uncertainty, nulls, identifiability, and explicit parameter counts.

POST/api/v1/batches

Compose reusable field solves across uploaded or generated systems, propagate baryonic weights, and download unweighted and weighted per-realization and per-radius reports.

POST/api/v1/runs

Run a formula and receive scores, curves, comparators, and an immutable manifest hash.

POST/api/v1/twin-runs

Regenerate a galaxy's baryonic radial twin without its measured speeds, then reveal and score the held-out rotation curve.

GET/api/v1/resolved-twin-evidence

Retrieve four development, two validation, and two one-shot final-holdout results with separate morphology, transport, observed-velocity, and viewing-geometry scores.

GET/api/v1/cluster-evidence

Inspect four RELICS baryon maps, model-derived lensing targets, raw-catalog readiness, provenance hashes, and blockers without confusing their scientific roles.
