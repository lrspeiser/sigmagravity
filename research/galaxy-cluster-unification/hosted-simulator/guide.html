Researcher guide · v0.18

Know what the simulator tested—and what it did not.

The live site is a useful radial formula benchmark and an auditable front door for richer field models. The repository also has a tested local 2D/3D worker. Those are different capabilities, and this page keeps the boundary visible.

See real requests and responses Open the workbench

The shortest honest description

Hosted now: test bounded radial acceleration formulas against 175 SPARC galaxies, inspect frozen resolved evidence, and validate an exact 2D/3D model manifest.

Not hosted yet: execute arbitrary 2D/3D equations or run new raw cluster-lensing solves. Those jobs work only through the repository's local reference backend.

02

Describe a 3D field theory exactly

Start with the published Refracted Gravity or nonlocal baryonic-response example, edit it, validate it, inspect the canonical model, then confirm that exact hash.

POST /api/v1/models/validate, conceptual input

{
  "schemaVersion": "sigma-field-model/1",
  "name": "Researcher's 3D field law",
  "modelClass": "stationary_elliptic",
  "geometry": {"coordinateSystem": "cartesian_3d", "dimensions": 3},
  "fields": ["typed scalar/vector/tensor declarations"],
  "equations": ["typed operators, sources, and couplings"],
  "parameters": ["values, units, bounds, and policy"],
  "boundaryConditions": ["declared conditions"],
  "observables": ["matter, photons, or both"],
  "solver": {"family": "nonlinear_finite_volume"}
}

{
  "valid": true,
  "modelSha256": "4a0c9be0...fea5d14bef",
  "confirmation": {"confirmed": true},
  "requiredCapabilities": {
    "coordinateSystem": "cartesian_3d",
    "solverFamily": "nonlinear_finite_volume",

What this proves: the service can represent, unit-check, hash, and audit the model. On Vercel it has not solved the equation. The local worker must be used for that today.
Nonlocal example: the source term adds q integral K(y-x) rho_b(x) dV. The local worker uses a centered, same-size, linear convolution, treats values beyond the submitted domain as zero, multiplies by cell volume, and never normalizes K automatically. The output is a potential field, a massive-tracer acceleration field, residual history, and an exact record of those numerical conventions.

What it outputs: a normalized 2D or 3D kernel with 95% intervals, one shared amplitude, per-system predictions and residuals, rank/nullity and compatible-kernel diagnostics, regularization sensitivity, radial-angle null scores, an HTML report, CSV/NPZ artifacts, hashes, and a reproduction command.
What this proves: the synthetic acceptance recovers a kernel deliberately injected into two systems. On real clusters it can show response families compatible with the chosen baryons and derived lens-model targets. It cannot show that gravity followed those routes, turn 25 fitted cells into a one-parameter theory, or validate itself. The next scientific step is to compress a development-set pattern into a small forward law, freeze it, and predict raw lensing on clusters whose target maps were never supplied.

05

Inspect frozen resolved evidence

Use GET /api/v1/resolved-twin-evidence?galaxy=NGC7331 to separate three questions.

  1. Generator fidelity: did the fake baryonic galaxy preserve the measured source map?
  2. Formula transport: did the same fixed equation return the same answer on the real and generated baryons?
  3. Observed accuracy: did either prediction match the real velocity field?
Current evidence: the eight-system protocol worked; fixed simple MOND was competitive but incomplete, while Newtonian baryons failed the declared holdout criterion. A faithful simulator can preserve a wrong formula, so these scores must remain separate.

Scientific boundary

What it cannot tell you yet

01

No causal discovery from a fit

A map that resembles a dark-matter reconstruction does not show that gravity flowed along the inferred paths. Multiple physical models can produce similar projected lensing.

02

No direct dark-matter image

A "dark-matter cloud" in a lens model is an inferred effective mass component, conditional on the lens equation, priors, baryonic model, geometry, and data. Raw image positions, shapes, time delays, shear, and magnification are the observations.

03

No unique 2D-to-3D galaxy

An image does not uniquely determine scale height, inclination, line-of-sight structure, gas flaring, or mass-to-light ratio. A serious generator must return posterior ensembles, not one invented truth.

04

No universal-theory verdict from one domain

Rotation curves alone do not establish lensing, Solar-System, stability, gravitational-wave, or cosmological behavior. The same frozen constants must survive all declared gates.

05

No fair win without parameter accounting

A one-parameter universal law and a flexible per-object halo fit answer different questions. Reports must show global, hierarchical, nuisance, and per-object parameter counts.

06

No theory result from numerical convergence

Convergence says the solver found a stable answer to the specified equations. It does not say the equations describe nature or that the inputs were complete.

Build next

From test bench to discovery instrument

The detailed repository roadmap defines data products, evidence gates, and failure conditions.

1

Connect production compute

Queue, isolated Python workers, durable metadata, object storage, authentication, quotas, cancellation, and signed artifacts.

2

Build the resolved evidence registry

Registered stellar, gas, intracluster-light, X-ray/SZ, velocity, strong-lensing, weak-lensing, PSF, WCS, uncertainty, license, and provenance products.

3

Finish uncertainty-aware galaxy twins

Infer posterior baryonic/observation parameters without velocity targets or gravity parameters, generate 3D ensembles, and recover withheld observations.

4

Make Sigma Gravity a first-class manifest

Represent scalar, vector, tensor, nonlocal, screening, photon, and matter terms with units, boundaries, universal parameters, and Solar-System limits.

5

Use halo maps only for discovery

Infer candidate baryon-to-effective-response kernels with null controls and uncertainty. Treat the answer as non-unique and never as proof of a path.

6

Freeze a forward law

Predict held-out raw lensing and galaxy velocities from baryons alone. The test system's inferred halo map cannot choose destinations or parameters.

7

Run one joint scorecard

Galaxies, clusters, Solar System, numerical stability, parameter counts, sensitivity, and blind holdouts in one deterministic report.

The finish line

A genuinely useful result is a prediction, not a reconstruction.

On a held-out cluster, the simulator must receive baryonic observations and a frozen universal formula, then predict raw multiple-image positions, shear or magnification, and dynamics without receiving the cluster's target halo map. On held-out galaxies, the same constants must predict velocity fields. The report must compare baryons-only GR, fixed MOND/RAR, and dark-matter models while disclosing parameter counts and uncertainty.
